
# Smart Expense Management Platform

A web-based expense tracking and management platform designed to help users efficiently monitor, organize, and analyze their financial transactions. Developed as a graduation project for Management Information Systems (MIS).

##  Key Features
- *Expense Tracking:* Add, categorize, and manage daily expenses seamlessly.
- *Financial Analytics:* Overview of cash flow and financial summaries.
- *Database Management:* Secure and structured data handling using MySQL.
- *System Architecture:* Designed with comprehensive UML and ERD models using MySQL Workbench.

##  Tech Stack
- *Backend:* Node.js, Express.js
- *Database:* MySQL / MySQL Workbench
- *Architecture & Tools:* RESTful APIs, Git
